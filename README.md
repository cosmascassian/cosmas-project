SWAHILI FOOD RESTAURANT WEBSITE

Project Description

This is a simple restaurant website called Swahili Food Restaurant. The website was created using HTML, CSS, PHP, and JavaScript.
The purpose of this project is to help customers view food items, place orders, and see the total cost of their orders.

Features

- View available food items
- See food prices
- Enter order quantity
- Submit food orders
- View order summary and total cost
- View contact information

Technologies Used

- HTML
- CSS
- PHP
- JavaScript

Files in the Project

- index.php - Main page of the website
- food.php - Processes customer orders
- food.css - Styles the website
- food.js - Adds simple interactivity

How the Website Works

1. Open the website.
2. View the food menu.
3. Enter the quantity of food you want.
4. Click the Order button.
5. The system calculates the total cost.
6. The order details are displayed on the receipt page.
